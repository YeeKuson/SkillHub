html-exhibition

把项目讲成一条可验证的叙事线。

极客定位不是炫技，而是把判断、证据和机制写得足够清楚。页面只负责放大这条主线。

01 / Positioning

默认左对齐，让观众沿着判断往下读。

每一屏只承担一个判断：先给结论，再给证据，最后解释机制。设计不抢叙事的方向。

Problem
PPT 风堆字会让重点消失。

Insight
左对齐叙事流天然适合解释工程判断。

Proof
代码、数据、截图只在支撑判断时出现。

02 / System

颜色只做一件事：标出当前最重要的线索。

#05080c

页面最深背景

#0f1a22

卡片和代码抬升层

#38f9d7

唯一主强调色

03 / Typography

四级字号，避免页面临场发散。

大标题 48-72px，中标题 24-32px，正文 16-18px，注释 13-14px。紧凑感来自信息密度和留白，不来自负字距。 

:root {
  --fs-hero: 64px;
  --fs-heading: 28px;
  --fs-body: 17px;
  --fs-note: 14px;
  letter-spacing: 0;
}

04 / Spacing

网页要空，但不是随便空。

所有间距只从 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128 中取值；留白负责建立节奏，卡片只负责承载证据。
