06 / BOUNDARY

克制是一种架构

第一版刻意不做“大系统”。

NOT NOW

砍掉复杂基础设施

  • 不做数据库与向量库
  • 不做 Web UI 与账号系统
  • 不做云同步与多人协作
  • 不把所有输入自动变成知识

SO THAT

保住可读与可回退

  • Markdown 人和 AI 都能直接读
  • 原料只读，错误不会污染事实层
  • Git diff 让每次变化可追溯
  • 脚本做机械活，Agent 做语义判断

当前边界：语义编译仍依赖 Agent，长期自用价值和产品化路径仍需继续验证。
