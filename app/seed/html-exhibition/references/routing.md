# 路由契约

把“怎么观看”和“怎么维护”分开判断，禁止用一个问题同时决定两者。

## 维度一：阅读方式

| 模式 | 选择条件 | 默认行为 |
|---|---|---|
| `scroll` | 自助阅读、发链接、作品集、异步评审、移动端浏览 | 纵向章节、滚动触发、可用翻页键跳到相邻章节 |
| `stage` | 答辩、路演、现场分享、翻页笔、演讲者视图、固定 16:9、PDF | 一次显示一页、fragment 优先、键盘和翻页笔导航 |

用户提到现场、答辩、演讲、翻页或翻页笔时直接选 `stage`，不再询问这一维。

## 维度二：工程结构

| 模式 | 选择条件 | 输出 |
|---|---|---|
| `single` | ≤8 页、动画简单、一次性交付、明确要求单文件 | 一个语义化 HTML，CSS/JS 内联 |
| `modular` | 默认；复杂动画、多轮修改、多人或 Agent 维护 | HTML、styles、scripts、assets、brief、manifest |

创建文件前说明两种工程结构。用户不选、说“直接做”或“按默认”时选 `modular`。

## 四种组合

| 组合 | 是否支持 | 典型用途 |
|---|---|---|
| scroll + single | 支持 | 短作品展示、单文件分享 |
| scroll + modular | 默认 | 项目展示、异步阅读、持续迭代 |
| stage + single | 支持 | 短答辩、离线携带 |
| stage + modular | 现场默认 | 路演、正式演讲、复杂机制与翻页笔 |

## 停止条件

- 用户要求原生 `.pptx` 编辑：停止，路由到 PPTX 能力。
- 用户要普通网站、后台、落地页而非演示：停止，路由到网站开发能力。
- 无法确认事实且生成会产生误导：只输出待确认清单，不生成成品。
- 选中模板不支持 CJK 或目标模式：换候选，不擅自破坏模板设计系统。
