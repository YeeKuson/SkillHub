# 视觉规范

本文件定义 `html-exhibition` 的默认 `terminal-mint` 视觉语言。具体变量位于 `assets/themes/terminal-mint.css`，兼容入口位于 `assets/theme.css`。选择 34 套参考模板之一时，以其 `design.md` 重映射 token，但仍遵守本仓库的内容、交互和可访问性契约。

## 风格定位

深色科技底、单一薄荷绿强调、终端提示符和低透明度描边。整体应克制、清晰、偏工程感，避免常见的渐变营销页风格。

## 配色

- 背景使用 `#05080c`、`#091119`、`#0f1a22` 三个深色层级。
- 文字使用 `rgba(238,248,246,*)` 建立主次层级。
- 唯一默认强调色为 `#38f9d7`。
- 边框和强调背景使用低透明度强调色，避免实色粗描边和大面积渐变。

## 字体

- 正文：优先系统无衬线字体栈，中文使用可用的系统 CJK 字体。
- 等宽内容：使用系统等宽字体栈。
- 中文标题与长正文使用无衬线字体；代码、状态和终端提示使用等宽字体，避免 CJK 回退为宋体。

## 排版

- 使用四级固定字号，不使用连续 `vw` 缩放。
- 标题 `letter-spacing: 0`，不使用负字距。
- 正文行高保持在 `1.6` 左右。
- 内容左对齐，每个 section 只突出一个主判断。
- 层级之间保留足够垂直间距，可用细线分隔章节。

## 组件

- `.term-nav`：等宽字、`> ` 提示符、圆角和低透明度描边；用于状态行、步骤或页脚提示。
- `.takeaway`：低透明度强调背景；用于单个核心结论。
- `.prompt`：终端提示符点缀；每个页面应克制使用。

## 禁止项

- 紫色渐变、彩虹色阶和多强调色竞争。
- 大面积发光、装饰光斑、玻璃拟态堆叠。
- 负字距和视口宽度驱动的连续字号变化。
- 为装饰而添加的循环动画或鼠标跟随。

## 检查清单

- [ ] 默认主题强调色为 `#38f9d7`；选定模板或项目品牌色时按确认后的 token 使用。
- [ ] 边框和底色优先使用低透明度强调色。
- [ ] 字号、间距和组件复用主题变量。
- [ ] 页面保持左对齐叙事和清晰信息层级。
- [ ] 动效符合 `references/motion-grammar.md`。
